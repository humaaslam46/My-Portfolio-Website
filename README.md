##  Features

- **Animated Hero** — typewriter effect cycling through roles, floating particle canvas with mouse repulsion and connecting lines
- **Smooth Scroll Navigation** — active section highlighting on navbar as you scroll
- **Responsive Design** — mobile drawer navbar, fluid grids, fully usable on all screen sizes
- **Services Section** — 6 animated hover cards covering AI/ML, Web Dev, UI/UX, Technical Writing, Automation, Data Analysis
- **Projects Showcase** — 6 real projects with filterable tabs (All / AI·ML / Web Dev) and direct GitHub links
- **Pricing Plans** — 3 tiers (Starter $80 / Professional $200 / Advanced $400) with featured card highlight
- **Testimonials** — 6 reviews from real collaborators, teammates, and clients
- **Contact Form** — EmailJS-powered with client-side validation and success/error feedback
- **Custom Cursor** — palette-matched dot + outline cursor with hover scale effect (desktop)
- **Scroll Animations** — IntersectionObserver entrance animations on all sections and cards
- **Back to Top** — floating scroll-to-top button

##  Tech Stack

> No frameworks. No build tools. Pure hand-crafted HTML, CSS, and JavaScript.

| Layer | Technology |
|-------|-----------|
| **Structure** | HTML5 (semantic, single-page) |
| **Styling** | CSS3 · Tailwind CSS (utility base) · Custom `extra.css` |
| **Interactivity** | Vanilla JavaScript (ES6+) — no frameworks |
| **Animations** | CSS transitions · Canvas API (particles) · IntersectionObserver |
| **Fonts** | Playfair Display · DM Sans — Google Fonts |
| **Icons** | Font Awesome 6 |
| **Email** | [EmailJS](https://www.emailjs.com) |
| **Hosting** | Custom domain — [huma-aslam.site](https://huma-aslam.site) |

##  Run Locally

No installation required — zero dependencies, zero build step.

```bash
# 1. Clone the repository
git clone https://github.com/humaaslam46/portfolio.git
cd portfolio

# 2. Open directly in your browser
open index.html          # macOS
start index.html         # Windows

# OR use a local server (recommended — required for EmailJS)
npx serve .
# Visit http://localhost:3000
```

>  **Contact form:** Replace `service_ishcxqo`, `template_k9nyo11`, and the public key in `index.html` with your own [EmailJS](https://www.emailjs.com) credentials.

## Deployment

Live at **[huma-aslam.site](https://huma-aslam.site)**. To deploy your own copy:

1. Push all files to a GitHub repository
2. Connect to [Netlify](https://netlify.com) or [Vercel](https://vercel.com)
3. Set publish / root directory to `/` — no build command needed
4. Point your custom domain in DNS settings
